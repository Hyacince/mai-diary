# 麦记手账

个人麦当劳用餐账本。把 `build/MaiDiary-1.8.1.apk` 传到 Android 8.0 或更高版本的手机，用系统安装器打开即可。已有用户直接覆盖安装，可保留账本。界面使用 Android System WebView，建议使用已更新的版本。

## 记餐与统计

- 在「手账」选好日期，点「记一餐」。选择早餐、午餐或晚餐，添加商品和份数，输入优惠后的整餐实付金额。免费餐可填 0 元。
- 点开已保存的餐次可编辑或删除。每条记录保留当时的名称和热量，之后更新菜单不会改写过去的账单。
- 在「统计」按自然周、月、年汇总花费、餐数、已知热量与单品排行。每周从周一开始。一次午餐吃两份薯条，会计入薯条的 1 餐、2 份。
- 1.3.0 增加「自定义」日期范围，首尾两天都计入统计。点日期标题可选择整周、月份或年份；自定义日历先选开始日期，再选结束日期，可以跨月和跨年。支出趋势改为每天实付总额的平滑曲线，没有消费的日子为零，拖动下方滑块可查看日期和金额。长范围只压缩连续零支出的内部点，横轴仍按实际日期间隔显示。
- 打开「商品库」的商品详情可查看累计吃过几餐、几份。对已下载商品和自定义食品，可以保存自己核实的每份热量。记餐时也可以只修改这一餐的数值。

## 菜单和本地数据

安装包内含 128 个常驻商品和份量规格。营养计算器的千焦数据按每份除以 4.184 并四舍五入为大卡。「鸡肉小食」还收录麦麦脆汁鸡琵琶腿和带骨里脊，每份均为 1 块。官网列出的琵琶腿热量是 326 大卡，带骨里脊使用估算值。[麦当劳中国营养计算器](https://www.mcdonalds.com.cn/nutrition_calculator) · [麦麦脆汁鸡产品资料](https://www.mcdonalds.com.cn/know_your_icon/Bone-in-chicken)

「商品库 → 联网下载／联网更新」读取官网活动里的食品，包括海陆双全堡这类写在套餐搭配说明中的单品。打开「已下载」可查看最近同步和历史下载的商品，详情中可核对活动来源。实际供应以当地门店为准。[麦当劳中国新品优惠](https://www.mcdonalds.com.cn/news/sales)

下载的商品优先使用同名同规格的官方营养数据。缺少官方数值时，应用按品类估算单份热量，并在商品、餐次和统计中标明。填写个人热量后，之后记餐优先使用个人数值。更新应用或重新同步不会重算已经保存的餐次。

1.1.0 增加了页面进退、数量变化、对话框、保存提示和统计柱图动画，下载中显示转动图标。系统开启“减少动态效果”时会关闭这些动画。

账本、自定义食品和下载的商品保存在手机的应用私有目录。卸载或清除应用数据会清除这些记录。使用同一签名的 APK 覆盖升级可保留数据。

## 从源码构建

在 Android Studio 打开本目录，安装 SDK Platform 35 和 Build Tools 35.0.1。Windows 也可使用 JDK 17 或 21 直接构建，先设置 `JAVA_HOME`、`ANDROID_HOME`，然后运行：

```powershell
.\build-apk.ps1
```

脚本生成 `build/MaiDiary-1.8.1.apk`，并验证 APK 签名。首次构建会生成本地签名文件 `.signing/local.keystore`。保留该文件可沿用对应安装包的签名。

运行账本、统计与界面测试：

```powershell
node --test tests/catalog.test.js tests/ledger.test.js tests/stats-ui.test.js tests/history.test.js
# 提供可用的 Playwright/Chromium 后执行
node tests/mobile-flow.cjs
```

移动端界面测试也支持通过环境变量 `PLAYWRIGHT_MODULE` 和 `BROWSER_PATH` 指定本机的 Playwright 模块与浏览器。Java 离线测试位于 `tests/CampaignParserTest.java` 与 `tests/NutritionMenuTest.java`，营养计算器测试需提供 `org.json` 运行时。

1.2.0 将底部导航栏固定在独立布局区域，主页面支持左右滑动切换。手账、统计、商品库按顺序切换，支持跟手移动和短划回弹。商品分类的横向滚动、竖向浏览和表单操作保留各自手势。

1.4.0 删除手账底部的常驻菜单推荐，将统计页的用餐明细移到手账底部。明细默认展开，按当前所选月份、日期倒序显示，每天附用餐次数和实付合计；较多记录可继续加载，整天的记录不会拆开。点击餐次仍可查看、编辑和删除，从详情返回保留列表位置。在上方日历切换月份即可查看对应月份的明细。

1.5.0 餐品排行统一按食用份数降序排列，移除餐数／份数切换和排行中的餐数显示。增加与选择食品相同的横向分类筛选，分类顺序来自同一份商品库；分类只影响排行，不影响总支出、热量和趋势图。

1.6.0 手账用餐日历与统计日期选择统一采用底部抽屉，从底部滑入并向下收回。支持下拖顶部手柄、点击上方遮罩、取消和返回键关闭；仅点击确定才保存所选日期。短距离拖动或系统取消手势时回弹。周、月、年和手账单日的黄色选中背景平滑移动，日期文字保持稳定；尊重系统减少动态效果设置。

1.7.0 日期格没有实付金额时显示农历，初一显示农历月份，保持两行内容居中；有金额（含零元餐）时优先显示金额。农历使用设备内置中文日历能力离线计算，不支持该能力的旧 WebView 显示星期。修复首列、末列选中背景被范围圆角覆盖的问题，单日选中背景按正圆居中计算。日期面板支持左右滑动：日／周／自定义视图翻月，月份视图翻年，年份视图翻十二年；短划、取消手势和竖向滚动不会触发翻页。

农历校验参考：[香港天文台 2026 年 11 月年历](https://www.hko.gov.hk/en/gts/astron2026/files/2026cal11.pdf)。

1.7.1 修复自定义日期范围的首尾圆点与底条断开：黄色底条延伸到端点圆心，红色圆点覆盖在上层；单日范围只显示圆点。范围底条统一使用与其他日期选择相同的 #FFC72C 黄色。

1.8.0 自定义日期范围的起点在最右列、终点在最左列时不绘制外侧底条，避免圆点外露黄。商品类型切换与手账周日历加入独立选中背景平移动画。红色标题栏放入固定的顶部区域，内容独立滚动；安卓状态栏改为品牌红色与浅色图标，Android 15 及以上在系统安全区域绘制同色背景，标题内容仍避让状态栏和刘海。添加自定义食品入口移到商品库／选择食品的「自定义」分类内。
